## 登录失败怎么办？

### 解决方案

A：尝试切换网络、重启手机、开启飞行模式再关闭后重新登录，或切换 Wi-Fi/流量多次尝试。

## 提示“账号密码错误”？

### 解决方案

【**禁止在设置登录**】【**请去AppStore登录**】请确保复制粘贴无误，注意大小写、不要留有空格检查复制内容是否包含空格，账号仅只能在 App Store 登录！

## App Store 登录账号提示：Apple账号已锁定

App Store 登录账号提示以下信息

>Apple账号已锁定
>
>处于安全原因，你的 Apple 账号已被锁定。若要解锁，你必须验证你的身份。

### 解决方案

1. 打开 Apple 忘记密码官网：[https://iforgot.apple.com/password/verify/appleid?language=zh_CN](https://iforgot.apple.com/password/verify/appleid?language=zh_CN)
2. 输入账号和验证码，通过**密保信息**进行验证
3. 验证密码即可解锁账号

## App Store下载小火箭提示：你的账户已在 App Store 和 iTunes 中被禁用。

### 解决方案

1. 卸载删除本机已有的旧版小火箭软件
2. 重新在App Store进行下载即可


## 登录App Store后搜索不到Shadowrocket？

### 解决方案

关闭App Store重新进入或重启手机即可。
